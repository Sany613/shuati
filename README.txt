当前版本：V6.8

刷题通 V6.8

功能：多题库管理、JSON/CSV/TXT/XLSX导入、手机本地题库格式转换、自动识别题型、自动去重、题库合并、随机/顺序/专项/自定义练习、错题本、收藏、50题45分钟模拟、答题卡、章节统计、每日目标、学习记录备份、PWA离线。

本版本新增：
- 🛠️ 题库格式转换器：在题库管理中打开“格式转换器”。
- 📱 转换在当前手机/浏览器本地完成，文件不会上传服务器。
- 📊 支持 JSON、CSV、TXT、XLSX、XLS 的读取与转换，并可预览转换结果。
- 🧠 自动识别单选、多选、判断、填空；也可以手动将整批题目指定为某一种题型。
- ⬇️ 可以把转换后的题库导出为标准 JSON，再导入或分享给其他设备。
- 📝 填空题会保留答案并使用输入框作答；选择题保留选项。

部署：将本目录所有文件上传到 GitHub Pages 的 main 分支根目录。

题库导入：手机打开设置 → 题库管理 → 导入题库；也可以打开“格式转换器”进行预览、修正题型后再导入。

格式说明：XLSX（新版 Excel）支持直接在手机本地解析。旧版 XLS（Excel 97-2003 二进制格式）现在也支持直接在手机浏览器本地解析，无需先用 WPS/Excel 转格式。

注意：学习记录默认只保存在当前浏览器。换手机前请在设置中导出学习记录。


V6.8 修复：题库格式转换器文件选择后的解析触发问题；兼容 JSON 中 options 为 {A,B,C,D} 对象格式；无选项但有普通答案时可自动识别为填空题。


V6.8 修复：旧版 .xls（BIFF8）共享字符串跨 CONTINUE 记录解析问题。大题库不再只识别到前面少量题目。

【版本号维护规则】
以后每次发布新版本，首页“刷题通”后面的版本号必须常驻显示，并与实际版本同步。更新时至少同步检查：① index.html 首页品牌版本号；② README.txt 版本号；③ sw.js 的 CACHE_NAME。不要在更新功能时删除首页版本标识。

V6.8 新增：题库导入后自动校验选择题选项、答案格式、判断题答案和填空题答案；发现问题时会在预览中明确提示，并阻止有问题的题库直接导入。


V6.8 新增：题库导入自动修正。会自动处理中文选项字段（选项A/B/C/D）、选项前缀、单选/多选答案格式、判断答案格式等；修正后再进行校验，减少正常题库被误判。

V6.8 修复：旧版 XLS 的公式字符串单元格（Formula + STRING）现在可正确读取；同时自动把少数无 A-D 选项但答案为文字的误标“单选题”纠正为填空题。
版本号必须同步更新：首页品牌“刷题通 Vx.x”、README、Service Worker CACHE 三处保持一致。
