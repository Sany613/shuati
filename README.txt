刷题通 V6.1

功能：多题库管理、JSON/CSV/TXT/XLSX导入、自动去重、题库合并、随机/顺序/专项/自定义练习、错题本、收藏、50题45分钟模拟、答题卡、章节统计、每日目标、学习记录备份、PWA离线。

部署：将本目录所有文件上传到 GitHub Pages 的 main 分支根目录。

题库导入：手机打开设置 → 题库管理 → 导入题库。支持 JSON、CSV、TXT、XLSX。老式 XLS 请先另存为 XLSX 或 CSV。

注意：学习记录默认只保存在当前浏览器。换手机前请在设置中导出学习记录。

本版本重点修复：填空题输入后确认误提示未填写；多选题支持同时选择多个选项并明确显示“（多选题）”；切题/交卷前自动同步填空输入。
